# Jumia Product Performance Dashboard

## Project Overview
An interactive Microsoft Excel dashboard that analyzes Jumia product pricing, discounts, customer reviews, and ratings to understand product performance and customer engagement.

## Business Questions
- Do products with bigger discounts receive more reviews?
- How do prices and discounts relate to customer engagement?
- Which products have high ratings and strong review activity?
- Which products may need pricing or marketing attention?

## Tools & Technologies
- Microsoft Excel
- Data Cleaning and Formatting
- PivotTables and PivotCharts
- Excel Charts and Slicers
- Conditional Formatting

## Project Workflow
1. **Data Cleaning:** Identified duplicate records, handled missing values, and standardized prices, discounts, and ratings.
2. **Data Analysis:** Used PivotTables to explore product performance and customer engagement.
3. **Data Visualization:** Built charts and an interactive dashboard to summarize key findings.
4. **Business Insights:** Organized the results to support product pricing and marketing decisions.
